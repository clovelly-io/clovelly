# Image manifest

Every package in the runtime closure of the cell images (`image-prod`,
`image-test` and the test-only refusal images, which share `image-test`'s root), with
its version and licence as recorded in the pinned nixpkgs. Generated by
`release/nix.sh build-to manifest build/manifest`, which walks the build graph of the
images' inputs and keeps every package with an output in the closure; the kernel and
systemd-stub, which are built into the UKI rather than referenced from the root, are
added by name.

Our own code (cell-agent, egress-proxy, base-bundle's assembly) is FSL-1.1-ALv2 (`LICENSE`); the
vendored gVisor `runsc` is Apache-2.0. Everything else is a base-OS component and is exempt from the dependency
licence allowlist under the licence rule in SPEC.md ("Decided"). None is AGPL or carries
a non-commercial licence.

- curl, the Google tools (`go-tdx-guest-tools`, `gcetcbendorsement`, `attest-tools`) and
  their libraries (nghttp2/3, ngtcp2, libssh2, libpsl, krb5, openssl, …) are in
  `image-test` only.
- chrony (phase 5: time from Google's NTP on the metadata server, SPEC.md "The cell")
  and its libraries (gnutls, nettle, gmp, libtasn1, p11-kit, unbound, libidn2,
  libunistring, libedit, libseccomp, libcap, libevent) are in both images.
- python3 and its libraries (sqlite, gdbm, Berkeley DB, readline, ncurses, mpdecimal,
  libffi, expat, …) are the sandbox base bundle's.
- Three paths the generator cannot attribute are base-OS data and runtime files; their
  nixpkgs licences: `iana-etc` 20251215 (MIT), `mailcap` 2.1.54 (MIT), and
  `xgcc-15.3.0-libgcc`, GCC's runtime library (GPL-3.0-or-later with the GCC Runtime
  Library Exception).
